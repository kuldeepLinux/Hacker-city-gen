- ⚔ **City Duel** — compare two cities side by side
- 💾 **Save/Load** cities (localStorage)
- 🗺 **Real map loader** (OpenStreetMap coordinates)
- 🎵 **Web Audio API** sounds (no external files)
- 📤 **PNG + JSON** export
